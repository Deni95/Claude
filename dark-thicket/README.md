# Шёпот леса

Мрачная игра на выживание для Android в рисованном «чернильном» стиле: тёмные ели, приглушённые краски, пустые белые глаза в темноте. Собирай ресурсы, мастери инструменты, следи за голодом и рассудком — и не оставайся ночью без света.

**Три героя на выбор:**
- *Странник* — крепок духом: рассудок 200, тьма пугает его меньше;
- *Охотница* — скорость +15%, урон +30%, но здоровье 120; начинает с копьём;
- *Мастер* — здоровье 180, инструменты служат вдвое дольше, но голод +20%; начинает с топором.

## Что есть в игре

- **Три показателя:** здоровье, сытость, рассудок. Без еды теряешь здоровье, в темноте и ночью — рассудок.
- **Смена дня и ночи** (полный день — 4 минуты). Ночью без костра или факела тебя атакует тьма.
- **Процедурный мир** 3000×3000: лес, луга, каменистые пустоши.
- **Ресурсы:** деревья, ветки, трава, ягодные кусты, морковь, валуны, кремень.
- **Создание:** топор, кирка, факел, верёвка, силок, целебная мазь, лежанка, копьё, костёр, каменный очаг, деревянная броня, похлёбка.
- **Готовка** на огне; топливо для костра.
- **Существа:**
  - на поверхности: зайцы, вепри, лесные пауки (дают верёвку), стая волков каждую третью ночь, мороки при низком рассудке;
  - ночью: нетопыри (быстрые, летят зигзагом и перелетают стены), с 4-го дня — упыри (медленные, но очень сильные; на рассвете уходят в землю);
  - в пещерах: слепые ползуны, нетопыри, плевуны (стреляют издалека — уворачивайся) и страж в конце каждого уровня.
- **Уровни героя:** опыт даётся за сбор, добычу, охоту, создание, стройку и каждый прожитый день. Новый уровень — здоровье +10 и урон +6%.
- **Пещеры:** четыре входа среди скал. Внутри всегда темно — нужен факел или фонарь. В залах руда, светогрибы и твари; в последнем зале страж. С него падает «Сердце глубин» (+25 здоровья навсегда) и открывается спуск на следующую, более опасную глубину. Из руды делаются стальной клинок (урон 75) и фонарь.
- **Бой с уворотом:** враг замирает и замахивается (над ним «!») — отойди, и удар пройдёт мимо.
- **Силки:** поставь на лугу — зайцы сами в них попадаются.
- **Лежанка:** сон у горящего костра пропускает ночь, лечит и возвращает рассудок (но тратит сытость).
- **Шишки:** падают с деревьев, их можно посадить — вырастет новое дерево.
- **Цветы:** срывание успокаивает; из лепестков делается целебная мазь.
- **Стрелка к дому:** указывает на ближайший костёр, когда он за экраном.
- **Строительство** (меню ⚒ → «Строить», затем веди героя и жми «Строить» — постройки ставятся по сетке):
  - *Стена* — не пускает зверей; враги ломают её, если она мешает добраться до тебя;
  - *Дверь* — ты проходишь, звери нет;
  - *Склад* — хранит вещи (8 → 12 → 16 ячеек);
  - *Башня* — сама стреляет по волкам, морокам и разъярённым вепрям.
- **Улучшения:** нажми на постройку — улучшить (дерево → камень → укреплённая: больше прочности, у башни — дальность, урон и скорострельность), починить или разобрать. Костёр улучшается до каменного очага. Инструменты и броня улучшаются в меню создания: крепкий топор и кирка (вдвое быстрее), тяжёлое копьё, окованная броня.
- **Звук:** ветер, птицы днём, сверчки и сова ночью, треск костра, тихая мелодия и звуки действий — всё синтезируется на лету, без аудиофайлов. Выключается в меню паузы.
- Автосохранение, рекорд по дням.

## Управление

- Левая половина экрана — джойстик.
- **«Действие»** (удерживать) — идти к ближайшей цели и взаимодействовать: собрать, рубить, добыть, атаковать, поднять.
- **⚒** — меню создания.
- Нажатие на ячейку инвентаря — съесть / приготовить / в костёр / экипировать / выбросить.
- На ПК: WASD, пробел — действие, C — создание, 1–0 — быстрое использование.

## Как получить APK

**GitHub Actions:** каждый push в `dark-thicket/` собирает APK. Скачать: вкладка *Actions* → последний запуск → артефакт `dark-thicket-apk`.

**Локально** (нужны Node.js 20+, JDK 21, Android SDK):

```
cd dark-thicket
npm install
npx cap add android
./scripts/patch-android.sh
npx cap sync android
cd android && ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

**Без сборки:** `npm run serve` и откройте `http://<ip>:8080` в Chrome на телефоне.

## iPhone

Игра работает в Safari и ставится на экран «Домой» как приложение — без Mac и без платного аккаунта Apple.

1. Один раз включите публикацию: в репозитории *Settings → Pages → Source: GitHub Actions*. После этого каждый push в `main` выкладывает игру (workflow `dark-thicket-pages.yml`), адрес появится на той же странице настроек.
2. Откройте этот адрес на iPhone **в Safari**.
3. Нажмите «Поделиться» → **«На экран "Домой"»**.
4. Запускайте игру с иконки: она откроется на весь экран и будет работать без интернета. Телефон нужно держать горизонтально.

Сохранения хранятся на самом телефоне. Настоящее приложение для App Store потребует Mac с Xcode и аккаунт Apple Developer.

## Файлы

- `www/` — сама игра (HTML5 Canvas, чистый JS, без зависимостей)
- `capacitor.config.json` — обёртка в Android-приложение
- `scripts/patch-android.sh` — альбомная ориентация, полный экран, экран не гаснет
